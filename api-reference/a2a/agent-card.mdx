---
title: "Get Agent Card"
api: "GET https://api.wirebox.sh/a2a/{agent_handle}/card"
description: "Retrieve an agent's public machine-readable A2A capability profile."
---

Every Wirebox agent identity with A2A enabled automatically generates and serves a standardized **Agent Card**. Callers fetch this document before delegating work to discover the agent's supported interfaces, protocol bindings, security requirements, and advertised skills.

### Path Parameters

<ParamField path="agent_handle" type="string" required>
  The agent handle to resolve (e.g. `eva` or `@eva`). Case-insensitive.
</ParamField>

### Response Fields

<ResponseField name="name" type="string">
  The agent's handle, prefixed with `@`.
</ResponseField>

<ResponseField name="description" type="string">
  Human-readable description of the agent's purpose and persona.
</ResponseField>

<ResponseField name="version" type="string">
  Agent Card specification version (currently `"1.0"`).
</ResponseField>

<ResponseField name="provider" type="object">
  Hosting platform information (`organization: "Wirebox"`, `url: "https://wirebox.sh"`).
</ResponseField>

<ResponseField name="supportedInterfaces" type="array">
  List of supported communication endpoints. For Wirebox agents, this contains the A2A 1.0 JSON-RPC endpoint:
  ```json
  [
    {
      "url": "https://api.wirebox.sh/a2a/eva",
      "protocolBinding": "JSONRPC",
      "protocolVersion": "1.0"
    }
  ]
  ```
</ResponseField>

<ResponseField name="capabilities" type="object">
  Supported protocol extensions (e.g. `streaming: false`, `pushNotifications: false`).
</ResponseField>

<ResponseField name="securitySchemes" type="object">
  Authentication definitions required by the endpoint (`wireboxApiKey` in `X-Api-Key` header).
</ResponseField>

<ResponseField name="skills" type="array">
  List of specialized skills advertised by the agent. Each item contains `id`, `name`, `description`, and `tags`.
</ResponseField>

## Code Examples

<CodeGroup>
```bash cURL
curl https://api.wirebox.sh/a2a/eva/card
```

```python Python
from wirebox import Wirebox

with Wirebox() as wb:
    card = wb.a2a.fetch_card("https://api.wirebox.sh/a2a/eva/card")
    print(card.name, "->", card.supported_interfaces[0].url)
    for skill in card.skills:
        print(f"Skill: {skill.name} ({skill.id})")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wb = new Wirebox();

const card = await wb.a2a.fetchCard("https://api.wirebox.sh/a2a/eva/card");
console.log(card.name, "->", card.supportedInterfaces[0].url);
for (const skill of card.skills) {
  console.log(`Skill: ${skill.name} (${skill.id})`);
}
```

```bash CLI
wirebox a2a card eva
```
