---
title: "Get a Phone Message"
api: "GET https://api.wirebox.sh/api/v1/phone/numbers/{number}/messages/{message_id}"
description: "Retrieve a single inbound SMS or MMS message."
---

<ParamField path="number" type="string" required>
  Number ID (`pn_...`), E.164 phone number, or owning agent handle.
</ParamField>

<ParamField path="message_id" type="string" required>
  Message ID (`msg_...`).
</ParamField>

<RequestExample>
```bash CLI
wirebox phone message eva msg_01J8DEF789KLM012
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wb = new Wirebox();
const eva = await wb.identify("eva");
const msg = await eva.phone.getMessage("msg_01J8DEF789KLM012");

console.log(`[${msg.from_number}] ${msg.text}`);
```

```python Python
from wirebox import Wirebox

with Wirebox() as wb:
    eva = wb.get_identity("eva")
    msg = eva.phone.get_message("msg_01J8DEF789KLM012")
    print(f"[{msg.from_number}] {msg.text}")
```
</RequestExample>
