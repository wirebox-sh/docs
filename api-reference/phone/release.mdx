---
title: "Release a Phone Number"
api: "DELETE https://api.wirebox.sh/api/v1/phone/numbers/{number}"
description: "Release a phone number while keeping its agent identity active."
---

<ParamField path="number" type="string" required>
  Number ID (`pn_...`), E.164 phone number, or owning agent handle.
</ParamField>

This operation is irreversible. The number is released to the carrier and may later be assigned to another customer. Message history is retained.

<RequestExample>
```bash CLI
wirebox phone release eva --yes
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wb = new Wirebox();
await wb.phone.numbers.release("eva");
```

```python Python
from wirebox import Wirebox

with Wirebox() as wb:
    wb.phone.numbers.release("eva")
```
</RequestExample>

<ResponseExample>
```text 204 No Content
```
</ResponseExample>
