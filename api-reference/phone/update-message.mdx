---
title: "Update a Phone Message"
api: "PATCH https://api.wirebox.sh/api/v1/phone/numbers/{number}/messages/{message_id}"
description: "Mark an inbound SMS or MMS message as read or unread."
---

This endpoint updates message metadata only. The message body, sender, recipients, and timestamp cannot be changed.

<ParamField path="number" type="string" required>
  Number ID (`pn_...`), E.164 phone number, or owning agent handle.
</ParamField>

<ParamField path="message_id" type="string" required>
  Message ID (`msg_...`).
</ParamField>

<ParamField body="is_read" type="boolean" required>
  Set to `true` to mark the message read or `false` to mark it unread.
</ParamField>

<RequestExample>
```bash CLI
wirebox phone mark-read eva msg_01J8DEF789KLM012
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wb = new Wirebox();
const eva = await wb.getIdentity("eva");
const msg = await eva.phone.markMessageRead("msg_01J8DEF789KLM012");

console.log(`Message ${msg.id} read status: ${msg.is_read}`);
```

```python Python
from wirebox import Wirebox

with Wirebox() as wb:
    eva = wb.get_identity("eva")
    msg = eva.phone.mark_message_read("msg_01J8DEF789KLM012")
    print(f"Message {msg.id} read status: {msg.is_read}")
```
</RequestExample>
