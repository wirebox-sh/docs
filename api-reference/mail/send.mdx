---
title: "Send Email"
api: "POST https://api.wirebox.sh/api/v1/mail/send"
description: "Send an outbound email or reply to an ongoing conversation thread."
---

### Body Parameters

<ParamField body="agent" type="string" required>
  The agent handle sending the email (e.g. `eva`).
</ParamField>

<ParamField body="to" type="string[]" required>
  Array of recipient email addresses.
</ParamField>

<ParamField body="subject" type="string" required>
  Email subject line.
</ParamField>

<ParamField body="text" type="string" required>
  Plain-text message body.
</ParamField>

<ParamField body="html" type="string">
  Optional HTML formatted body.
</ParamField>

<ParamField body="thread_id" type="string">
  Optional thread ID to reply to. Wirebox will set RFC `In-Reply-To` and `References` headers automatically.
</ParamField>

<ParamField body="attachments" type="object[]">
  Optional array of file attachments. Each object contains `filename` (string), `content_type` (string), and `content` (base64 string).
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.wirebox.sh/api/v1/mail/send \
  -H "Authorization: Bearer $WIREBOX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "agent": "eva",
    "to": ["user@example.com"],
    "subject": "Re: Support Ticket #1042",
    "text": "Hello! Your ticket has been updated.",
    "thread_id": "thrd_01J8XYZ987ABC"
  }'
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    res = wirebox.send_email(
        agent="eva",
        to=["user@example.com"],
        subject="Re: Support Ticket #1042",
        text="Hello! Your ticket has been updated.",
        thread_id="thrd_01J8XYZ987ABC"
    )
    print("Sent message ID:", res.id)
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const res = await wirebox.sendEmail({
  agent: "eva",
  to: ["user@example.com"],
  subject: "Re: Support Ticket #1042",
  text: "Hello! Your ticket has been updated.",
  thread_id: "thrd_01J8XYZ987ABC",
});
console.log("Sent message ID:", res.id);
```

```bash CLI
wirebox mail send \
  --agent eva \
  --to user@example.com \
  --subject "Re: Support Ticket #1042" \
  --text "Hello! Your ticket has been updated."
```
