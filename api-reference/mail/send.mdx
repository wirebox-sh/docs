---
title: "Send Email"
api: "POST https://api.wirebox.sh/api/v1/mailboxes/{email_address}/messages"
description: "Send an outbound email from an agent mailbox and open a new conversation thread."
---

### Path Parameters

<ParamField path="email_address" type="string" required>
  Full mailbox address (`eva@wireboxmail.com`) or local agent handle (`eva`).
</ParamField>

### Headers

<ParamField header="Idempotency-Key" type="string">
  Optional client-generated token (UUID v4 or random ASCII string) that makes retries safe: replaying a request with the same key returns the original `201` response with an `Idempotent-Replayed: true` header instead of sending a second email.
</ParamField>

### Body Parameters

<ParamField body="to" type="string | string[]" required>
  Recipient email address or array of addresses.
</ParamField>

<ParamField body="subject" type="string" required>
  Email subject line (max 998 characters).
</ParamField>

<ParamField body="text" type="string">
  Plain-text body. At least one of `text` or `html` is required.
</ParamField>

<ParamField body="html" type="string">
  HTML formatted body.
</ParamField>

<ParamField body="cc" type="string | string[]">
  Optional CC recipients.
</ParamField>

<ParamField body="bcc" type="string | string[]">
  Optional BCC recipients.
</ParamField>

<ParamField body="reply_to" type="string | string[]">
  Optional Reply-To address(es).
</ParamField>

<ParamField body="attachments" type="object[]">
  Optional attachments. Each object requires `filename` and `content_type`, plus either `content` (base64 string) or `url` (publicly fetchable URL). `content_id` is optional.
</ParamField>

<ParamField body="headers" type="object">
  Optional custom RFC headers as a key/value map.
</ParamField>

<Note>
  To reply within an existing thread, use [`POST /mailboxes/{email_address}/messages/{message_id}/reply`](/capabilities/email#replying-to-existing-threads), which sets the RFC `In-Reply-To` and `References` headers automatically.
</Note>

### Response

<ResponseField name="id" type="string">
  Unique identifier of the sent message (`msg_` prefix).
</ResponseField>

<ResponseField name="thread_id" type="string">
  Conversation thread created (or reused) for this message.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "https://api.wirebox.sh/api/v1/mailboxes/eva/messages" \
  -H "Authorization: Bearer $WIREBOX_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: 3f9c1d0e-8a2b-4f6e-9c1d-0e8a2b4f6e9c" \
  -d '{
    "to": ["user@example.com"],
    "subject": "Your ticket has been updated",
    "text": "Hello! Your ticket has been updated."
  }'
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    eva = wirebox.get_identity("eva")
    res = eva.send_email(
        to=["user@example.com"],
        subject="Your ticket has been updated",
        text="Hello! Your ticket has been updated.",
    )
    print("Sent message ID:", res.id)
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const eva = await wirebox.getIdentity("eva");
const res = await eva.sendEmail({
  to: ["user@example.com"],
  subject: "Your ticket has been updated",
  text: "Hello! Your ticket has been updated.",
});
console.log("Sent message ID:", res.id);
```

```bash CLI
wirebox mail send \
  --identity eva \
  --to user@example.com \
  --subject "Your ticket has been updated" \
  --text "Hello! Your ticket has been updated."
```
