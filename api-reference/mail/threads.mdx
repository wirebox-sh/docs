---
title: "List Conversation Threads"
api: "GET https://api.wirebox.sh/api/v1/mailboxes/{email_address}/threads"
description: "List and retrieve RFC-grouped conversation threads for an agent mailbox."
---

### Path Parameters

<ParamField path="email_address" type="string" required>
  Full mailbox address (`eva@wireboxmail.com`) or local agent handle (`eva`).
</ParamField>

### Query Parameters

<ParamField query="limit" type="integer" default="50">
  Number of threads to return (1–100).
</ParamField>

### Response

<ResponseField name="threads[].id" type="string">
  Unique thread identifier (`thrd_` prefix).
</ResponseField>

<ResponseField name="threads[].mailbox_id" type="string">
  Mailbox this thread belongs to.
</ResponseField>

<ResponseField name="threads[].subject" type="string">
  Thread subject.
</ResponseField>

<ResponseField name="threads[].snippet" type="string">
  Short preview of the latest message.
</ResponseField>

<ResponseField name="threads[].folder" type="string">
  Folder the thread currently lives in (e.g. `inbox`).
</ResponseField>

<ResponseField name="threads[].message_count" type="integer">
  Number of messages in the thread.
</ResponseField>

<ResponseField name="threads[].has_attachments" type="boolean">
  Whether any message in the thread has attachments.
</ResponseField>

<ResponseField name="threads[].is_unread" type="boolean">
  Whether the thread has unread messages.
</ResponseField>

<ResponseField name="threads[].last_message_at" type="string">
  ISO 8601 timestamp of the most recent message.
</ResponseField>

<ResponseField name="threads[].created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.wirebox.sh/api/v1/mailboxes/eva/threads" \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```
</RequestExample>

<ResponseExample>
```json 200 OK
{
  "threads": [
    {
      "id": "thrd_01J8XYZ987ABC",
      "mailbox_id": "mbx_01J8ABC123XYZ",

      "created_at": "2026-09-11T12:00:00Z"
    }
  ],
  "next_cursor": null,
  "has_more": false

```
</ResponseExample>

## Retrieve a Thread

Returns a single thread with all of its messages inlined in chronological order.

### Path Parameters

<ParamField path="thread_id" type="string" required>
  Unique thread identifier (`thrd_` prefix).
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.wirebox.sh/api/v1/mailboxes/eva/threads/thrd_01J8XYZ987ABC" \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```
</RequestExample>

### Response

<ResponseField name="messages[].id" type="string">
  Unique message identifier.
</ResponseField>

<ResponseField name="messages[].direction" type="string">
  `inbound` or `outbound`.
</ResponseField>

<ResponseField name="messages[].status" type="string">
  Delivery status (`queued`, `sent`, `delivered`, `bounced`, or `failed`).
</ResponseField>

<ResponseField name="messages[].from" type="string">
  Sender email address.
</ResponseField>

<ResponseField name="messages[].to" type="string[]">
  Recipient email addresses.
</ResponseField>

<ResponseField name="messages[].cc" type="string[]">
  CC recipient email addresses.
</ResponseField>

<ResponseField name="messages[].subject" type="string">
  Message subject.
</ResponseField>

<ResponseField name="messages[].text" type="string">
  Plain-text body.
</ResponseField>

<ResponseField name="messages[].html" type="string">
  HTML body.
</ResponseField>

<ResponseField name="messages[].is_read" type="boolean">
  Whether the message has been read.
</ResponseField>

<ResponseField name="messages[].has_attachments" type="boolean">
  Whether the message has attachments.
</ResponseField>

<ResponseField name="messages[].created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>
