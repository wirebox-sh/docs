---
title: "List Conversation Threads"
api: "GET https://api.wirebox.sh/api/v1/mail/threads"
description: "Retrieve grouped conversation threads scoped to an agent or mailbox."
---

### Query Parameters

<ParamField query="agent" type="string">
  Filter threads for a specific agent handle (e.g. `eva`).
</ParamField>

<ParamField query="mailbox" type="string">
  Filter threads by mailbox address (e.g. `eva@wireboxmail.com`).
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Number of threads to return (1–100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Pagination offset.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.wirebox.sh/api/v1/mail/threads?agent=eva" \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    threads = wirebox.list_threads(agent="eva")
    for th in threads:
        print(f"Thread {th.id}: {th.subject} ({th.message_count} messages)")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const threads = await wirebox.listThreads({ agent: "eva" });
for (const th of threads) {
  console.log(`Thread ${th.id}: ${th.subject}`);
}
```

```bash CLI
wirebox mail threads --agent eva
```
</RequestExample>
