---
title: "Get Mailbox"
api: "GET https://api.wirebox.sh/api/v1/mailboxes/{email_address}"
description: "Retrieve a mailbox and its owning agent identity by full email address or local handle."
---

### Path Parameters

<ParamField path="email_address" type="string" required>
  Full mailbox address (`eva@wireboxmail.com`) or local agent handle (`eva`).
</ParamField>

### Response

<ResponseField name="id" type="string">
  Unique mailbox identifier.
</ResponseField>

<ResponseField name="email_address" type="string">
  Full email address of the mailbox.
</ResponseField>

<ResponseField name="agent_handle" type="string">
  Handle of the agent identity that owns this mailbox.
</ResponseField>

<ResponseField name="status" type="string">
  Mailbox status (`active`).
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<ResponseField name="updated_at" type="string">
  ISO 8601 update timestamp.
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.wirebox.sh/api/v1/mailboxes/eva" \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```

```bash CLI
wirebox identity get eva
```
</RequestExample>

<ResponseExample>
