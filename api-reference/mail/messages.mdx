---
title: "List Messages"
api: "GET https://api.wirebox.sh/api/v1/mailboxes/{email_address}/messages"
description: "List email message summaries in a mailbox, newest first."
---

### Path Parameters

<ParamField path="email_address" type="string" required>
  Full mailbox address (`eva@wireboxmail.com`) or local agent handle (`eva`).
</ParamField>

### Query Parameters

<ParamField query="limit" type="integer" default="50">
  Number of messages to return (1–100).
</ParamField>

<ParamField query="is_read" type="boolean">
  Filter by read state: `true` returns read messages, `false` returns unread messages.
</ParamField>

### Response

<ResponseField name="messages[]" type="object[]">
  Message summaries ordered by `created_at` descending.
</ResponseField>

<ResponseField name="messages[].id" type="string">
  Unique message identifier (`msg_` prefix).
</ResponseField>

<ResponseField name="messages[].thread_id" type="string">
  Conversation thread this message belongs to.
</ResponseField>

<ResponseField name="messages[].direction" type="string">
  `inbound` or `outbound`.
</ResponseField>

<ResponseField name="messages[].from" type="string">
  Sender email address.
</ResponseField>

<ResponseField name="messages[].to" type="string[]">
  Recipient email addresses.
</ResponseField>

<ResponseField name="messages[].subject" type="string">
  Subject line.
</ResponseField>

<ResponseField name="messages[].snippet" type="string">
  Short preview of the message body.
</ResponseField>

<ResponseField name="messages[].is_read" type="boolean">
  Whether the message has been read.
</ResponseField>

<ResponseField name="messages[].is_starred" type="boolean">
  Whether the message is starred.
</ResponseField>

<ResponseField name="messages[].has_attachments" type="boolean">
  Whether the message has attachments.
</ResponseField>

<ResponseField name="messages[].created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<ResponseField name="next_cursor" type="string | null">
  Pagination cursor. Reserved for future use; currently always `null`.
</ResponseField>

<ResponseField name="has_more" type="boolean">
  Whether more messages are available. Reserved for future use; currently always `false`.
</ResponseField>

<RequestExample>
```bash cURL
curl -X GET "https://api.wirebox.sh/api/v1/mailboxes/eva/messages?limit=20" \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    eva = wirebox.get_identity("eva")
    for msg in eva.iter_emails():
        print(f"[{msg.from_address}] {msg.subject}: {msg.snippet}")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const eva = await wirebox.getIdentity("eva");
const { messages } = await eva.listMessages({ limit: 20 });

for (const msg of messages) {
  console.log(`[${msg.from}] ${msg.subject}: ${msg.snippet}`);
}
```

```bash CLI
wirebox mail list --identity eva
```
