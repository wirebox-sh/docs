---
title: "List Messages"
api: "GET https://api.wirebox.sh/api/v1/mail/messages"
description: "List email messages with full RFC headers, text/HTML content, and R2 attachment URLs."
---

### Query Parameters

<ParamField query="thread_id" type="string">
  Filter messages belonging to a specific conversation thread.
</ParamField>

<ParamField query="agent" type="string">
  Filter messages for a specific agent handle.
</ParamField>

<ParamField query="limit" type="integer" default="50">
  Number of messages to return.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.wirebox.sh/api/v1/mail/messages?agent=eva" \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    identity = wirebox.get_identity("eva")
    for msg in identity.iter_emails():
        print(f"[{msg.from_address}] {msg.subject}: {msg.text}")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const identity = await wirebox.getIdentity("eva");
const messages = await identity.listMessages({ limit: 20 });

for (const msg of messages) {
  console.log(`[${msg.from}] ${msg.subject}`);
}
```

```bash CLI
wirebox mail list --agent eva
```
