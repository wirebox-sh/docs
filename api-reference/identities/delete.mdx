---
title: "Delete Agent Identity"
api: "DELETE https://api.wirebox.sh/api/v1/identities/{handle}"
description: "Permanently delete an agent identity and release all associated communication resources."
---

### Path Parameters

<ParamField path="handle" type="string" required>
  The agent handle to remove (e.g. `eva`).
</ParamField>

### Response

Returns `204 No Content` on successful deletion.

Deleting an identity removes its mailbox, tunnel, messages, and phone-message
history. If the identity owns a phone number, Wirebox releases the number with
its carrier before completing the deletion. If carrier release or tunnel
termination fails, the identity remains active and the request returns `502` so
you can retry safely.

### Errors

| Status | Code | Meaning |
| --- | --- | --- |
| 502 | `carrier_release_failed` | The linked phone number could not be released. Retry the request safely. |
| 502 | `tunnel_termination_failed` | The linked tunnel could not be terminated. Retry the request safely. |
| 500 | `deletion_rollback_failed` | Phone release failed and the tunnel could not be restored. Retry the request safely. |

<RequestExample>
```bash cURL
curl -X DELETE https://api.wirebox.sh/api/v1/identities/eva \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    wirebox.delete_identity("eva")
    print("Agent identity deleted")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
await wirebox.deleteIdentity("eva");
console.log("Agent identity deleted");
```

```bash CLI
wirebox identity delete eva
```
</RequestExample>

