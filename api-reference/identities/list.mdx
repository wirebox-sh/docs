---
title: "List Agent Identities"
api: "GET https://api.wirebox.sh/api/v1/identities"
description: "Retrieve all agent identities registered within your organization."
---

### Query Parameters

<ParamField query="limit" type="integer" default="50">
  Number of identities to return (1–100).
</ParamField>

<ParamField query="offset" type="integer" default="0">
  Number of records to skip for pagination.
</ParamField>

### Response

Returns an array of identity objects.

<RequestExample>
```bash cURL
curl -X GET "https://api.wirebox.sh/api/v1/identities?limit=20" \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    identities = wirebox.list_identities(limit=20)
    for ident in identities:
        print(f"@{ident.agent_handle} ({ident.mailbox.email_address})")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const identities = await wirebox.listIdentities({ limit: 20 });
```

```bash CLI
wirebox identity list
```
</RequestExample>
