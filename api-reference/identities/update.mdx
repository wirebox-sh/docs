---
title: "Update Agent Identity"
api: "PATCH https://api.wirebox.sh/api/v1/identities/{handle}"
description: "Update profile, channel, and mail guardrail settings for an existing agent identity."
---

### Path Parameters

<ParamField path="handle" type="string" required>
  The agent handle (e.g. `eva`).
</ParamField>

### Body Parameters

<ParamField body="display_name" type="string">
  Updated display name.
</ParamField>

<ParamField body="description" type="string | null">
  Updated description. Pass `null` to clear it; omit the field to leave it unchanged.
</ParamField>

<ParamField body="imessage_enabled" type="boolean">
  Enable or disable the Apple iMessage router channel.
</ParamField>

<ParamField body="mail_filter_mode" type="string">
  Legacy combined mail filter posture (`whitelist` or `blacklist`).
</ParamField>

<ParamField body="mail_inbound_filter_mode" type="string">
  Inbound guardrail posture: `whitelist` (only approved senders) or `blacklist` (open to anyone).
</ParamField>

<ParamField body="mail_outbound_filter_mode" type="string">
  Outbound guardrail posture: `whitelist` (only approved recipients) or `blacklist` (open to anyone).
</ParamField>

<ParamField body="custom_domain_id" type="string | null">
  Bind the identity's mailbox to a verified custom domain by ID. Pass `null` to reset to the default Wirebox domain.
</ParamField>

<ParamField body="domain" type="string | null">
  Bind the identity's mailbox to a verified custom domain by hostname. Pass `null` to reset to the default Wirebox domain.
</ParamField>

<Note>
  `agent_handle` is immutable and cannot be changed after creation.
</Note>

### Response

Returns the same identity object as [Create Agent Identity](/api-reference/identities/create), including `status`, `imessage_enabled`, the three mail filter modes, `email_address`, `mailbox`, and `tunnel`.

<RequestExample>
```bash cURL
curl -X PATCH https://api.wirebox.sh/api/v1/identities/eva \
  -H "Authorization: Bearer $WIREBOX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "display_name": "Eva Senior Support",
    "description": "Escalated support and billing queries"
  }'
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    eva = wirebox.get_identity("eva")
    eva.update(
        display_name="Eva Senior Support",
        description="Escalated support and billing queries"
    )
    print("Updated:", eva.display_name)
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const eva = await wirebox.getIdentity("eva");
const updated = await eva.update({
  display_name: "Eva Senior Support",
  description: "Escalated support and billing queries",
});
console.log("Updated:", updated.displayName);
```

```bash CLI
wirebox identity update eva \
  --display-name "Eva Senior Support" \
  --description "Escalated support and billing queries"
```
</RequestExample>
