---
title: "Update Webhook"
api: "PATCH https://api.wirebox.sh/api/v1/webhooks/{id}"
description: "Update destination URL, subscribed events, or authentication token."
---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique webhook ID.
</ParamField>

### Body Parameters

<ParamField body="url" type="string">
  New HTTPS destination URL.
</ParamField>

<ParamField body="events" type="string[]">
  Updated array of subscribed event types.
</ParamField>

<ParamField body="auth_token" type="string">
  Updated bearer token (or pass `null` to remove it).
</ParamField>

<RequestExample>
```bash cURL
curl -X PATCH https://api.wirebox.sh/api/v1/webhooks/whk_01J8DEF456GHI789 \
  -H "Authorization: Bearer $WIREBOX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "events": ["email.received", "email.sent", "email.delivered", "email.bounced"]
  }'
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    updated = wirebox.update_webhook(
        "whk_01J8DEF456GHI789",
        events=["email.received", "email.sent", "email.delivered", "email.bounced"]
    )
    print("Updated events:", updated.events)
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const updated = await wirebox.updateWebhook("whk_01J8DEF456GHI789", {
  events: ["email.received", "email.sent", "email.delivered", "email.bounced"],
});
console.log("Updated events:", updated.events);
```

```bash CLI
wirebox webhook update whk_01J8DEF456GHI789 \
  --events email.received,email.sent,email.delivered,email.bounced
```
</RequestExample>
