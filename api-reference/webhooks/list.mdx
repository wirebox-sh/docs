---
title: "List Webhooks"
api: "GET https://api.wirebox.sh/api/v1/webhooks"
description: "List all configured webhook subscriptions in your organization."
---

### Query Parameters

<ParamField query="agent" type="string">
  Filter webhooks scoped to an agent handle.
</ParamField>

<ParamField query="event" type="string">
  Filter webhooks subscribed to a specific event type.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "https://api.wirebox.sh/api/v1/webhooks?agent=eva" \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    webhooks = wirebox.list_webhooks(agent="eva")
    for wh in webhooks:
        print(f"Webhook {wh.id}: {wh.url} ({wh.events})")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const webhooks = await wirebox.listWebhooks({ agent: "eva" });
for (const wh of webhooks) {
  console.log(`Webhook ${wh.id}: ${wh.url}`);
}
```

```bash CLI
wirebox webhook list --agent eva
```
