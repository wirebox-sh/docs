---
title: "Webhook Event Catalog"
description: "Reference catalog and JSON payload schemas for Wirebox webhook events."
---

Wirebox triggers webhooks in real time whenever activity occurs across your communication channels. Every delivery is signed with HMAC-SHA256 — see [Signature Verification](/capabilities/webhooks#2-zero-trust-hmac-sha256-verification).

## Envelope

All events share the same envelope. The event-specific object lives under `data`:

```json
{
  "id": "evt_01J8ABC123",
  "event_type": "email.received",
  "timestamp": "2026-09-11T12:00:00Z",
  "data": { }
}
```

| Field | Type | Description |
| :--- | :--- | :--- |
| `id` | string | Unique, stable event ID (`evt_` prefix). Reuse it to deduplicate deliveries. |
| `event_type` | string | Event name (see below). |
| `timestamp` | string | ISO 8601 time the event was dispatched. |
| `data` | object | Event-specific payload. |

## Email Events

### `email.received`

Triggered when an incoming email arrives at an agent's inbox. Emails rejected by the agent's inbound guardrails are quarantined and never dispatched.

```json
{
  "id": "evt_01J8ABC123",
  "event_type": "email.received",
  "timestamp": "2026-09-11T12:00:00Z",
  "data": {
    "message": {
      "id": "msg_01J8DEF456",
      "mailbox_address": "eva@wireboxmail.com",
      "agent_handle": "eva",
      "thread_id": "thrd_01J8GHI789",
      "from": "Alex Customer <alex@example.com>",
      "to": ["eva@wireboxmail.com"],
      "cc": [],
      "subject": "Need help with integration",
      "snippet": "Hello, how do I connect my agent?",
      "sender_access": "default_allowed",
      "created_at": "2026-09-11T12:00:00Z"
    }
  }
}
```

`sender_access` reflects how the inbound guardrails classified the sender: `direct` (exact rule), `reply_thread` (continuing an outbound thread), or `default_allowed` (baseline posture).

---

### `email.sent`

Triggered when an outbound email (send, reply, or forward) is accepted by Wirebox for delivery.

```json
{
  "id": "evt_01J8ABC124",
  "event_type": "email.sent",
  "timestamp": "2026-09-11T12:01:00Z",
  "data": {
    "message": {
      "id": "msg_01J8OUTBOUND789",
      "mailbox_address": "eva@wireboxmail.com",
      "thread_id": "thrd_01J8GHI789",
      "from": "Eva Customer Support <eva@wireboxmail.com>",
      "to": ["alex@example.com"],
      "cc": [],
      "subject": "Re: Need help with integration",
      "snippet": "Happy to help — here is how to connect your agent.",
      "created_at": "2026-09-11T12:01:00Z"
    }
  }
}
```

## SMS Events

### `sms.received`

Triggered immediately when an incoming SMS or MMS arrives on an agent's phone number.

```json
{
  "id": "evt_01J8ABC140",
  "event_type": "sms.received",
  "timestamp": "2026-09-18T02:15:00Z",
  "data": {
    "message": {
      "id": "msg_01J8DEF111",
      "channel": "sms",
      "phone_number": "+14232190980",
      "agent_handle": "sale-mark",
      "direction": "inbound",
      "type": "sms",
      "from_number": "+15551234567",
      "to_numbers": ["+14232190980"],
      "text": "Your verification code is 482910",
      "media": null,
      "has_media": false,
      "segments": 1,
      "created_at": "2026-09-18T02:15:00Z"
    }
  }
}
```

## iMessage Events

### `imessage.connected`

Triggered when a human user connects to an agent via the router line (texting `connect @agent` or scanning the QR code).

```json
{
  "id": "evt_01J8ABC131",
  "event_type": "imessage.connected",
  "timestamp": "2026-09-17T10:28:00Z",
  "data": {
    "conversation_id": "conv_01J8ABC123XYZ",
    "identity_id": "ident_01J8ABC123XYZ",
    "agent_handle": "eva",
    "user_phone": "+15551234567",
    "connected_at": "2026-09-17T10:28:00Z"
  }
}
```

---

### `imessage.disconnected`

Triggered when an active iMessage conversation session is disconnected.

```json
{
  "id": "evt_01J8ABC132",
  "event_type": "imessage.disconnected",
  "timestamp": "2026-09-17T11:00:00Z",
  "data": {
    "conversation_id": "conv_01J8ABC123XYZ",
    "identity_id": "ident_01J8ABC123XYZ",
    "user_phone": "+15551234567",
    "status": "disconnected",
    "disconnected_at": "2026-09-17T11:00:00Z"
  }
}
```

---

### `imessage.received`

Triggered when an inbound blue bubble arrives from a user. The connection handshake itself is also delivered with `is_handshake: true`.

```json
{
  "id": "evt_01J8ABC127",
  "event_type": "imessage.received",
  "timestamp": "2026-09-17T10:30:00Z",
  "data": {
    "id": "msg_01J8DEF456GHI",
    "conversation_id": "conv_01J8ABC123XYZ",
    "identity_id": "ident_01J8ABC123XYZ",
    "direction": "inbound",
    "sender": "+15551234567",
    "text": "Hello Eva, can you summarize my tasks today?",
    "media_url": null,
    "created_at": "2026-09-17T10:30:00Z"
  }
}
```

---

### `imessage.sent`

Triggered when an outbound iMessage is accepted by the gateway.

```json
{
  "id": "evt_01J8ABC128",
  "event_type": "imessage.sent",
  "timestamp": "2026-09-17T10:30:05Z",
  "data": {
    "id": "msg_01J8DEF456GHJ",
    "conversation_id": "conv_01J8ABC123XYZ",
    "identity_id": "ident_01J8ABC123XYZ",
    "direction": "outbound",
    "to": "+15551234567",
    "text": "You have 3 tasks scheduled for today.",
    "media_url": null,
    "status": "sent",
    "error": null,
    "created_at": "2026-09-17T10:30:05Z"
  }
}
```

---

### `imessage.failed`

Triggered when an outbound iMessage send fails. The payload matches `imessage.sent` with `status` set to the failure state and `error` populated.

```json
{
  "id": "evt_01J8ABC130",
  "event_type": "imessage.failed",
  "timestamp": "2026-09-17T10:30:10Z",
  "data": {
    "id": "msg_01J8DEF456GHJ",
    "conversation_id": "conv_01J8ABC123XYZ",
    "identity_id": "ident_01J8ABC123XYZ",
    "direction": "outbound",
    "to": "+15551234567",
    "text": "You have 3 tasks scheduled for today.",
    "media_url": null,
    "status": "failed",
    "error": "Recipient is not registered with Apple iMessage",
    "created_at": "2026-09-17T10:30:10Z"
  }
}
```

## System Events

### `test.ping`

Diagnostic event sent only to the webhook being tested, via [Send Test Ping](/api-reference/webhooks/test-ping) or the Console.

```json
{
  "id": "evt_01J8TEST999",
  "event_type": "test.ping",
  "timestamp": "2026-09-11T12:00:00Z",
  "data": {
    "ping": "pong",
    "message": "This is a live test webhook notification from Wirebox.",
    "triggered_at": "2026-09-11T12:00:00Z"
  }
}
```
