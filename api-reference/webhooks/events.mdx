---
title: "Webhook Event Catalog"
description: "Reference catalog and JSON payload schemas for all Wirebox webhook events."
---

Wirebox triggers webhooks in real time whenever activity occurs across your communication channels. Events are signed with HMAC-SHA256 and structured by channel lifecycle.

---

## Email Events

### `email.received`

Triggered when an incoming email arrives at an agent's inbox.

```json
{
  "id": "evt_01J8ABC123",
  "event": "email.received",
  "created_at": "2026-09-11T12:00:00Z",
  "data": {
    "message_id": "msg_01J8DEF456",
    "thread_id": "thrd_01J8GHI789",
    "agent_handle": "eva",
    "mailbox_address": "eva@wireboxmail.com",
    "from": "Alex Customer <alex@example.com>",
    "to": ["eva@wireboxmail.com"],
    "subject": "Need help with integration",
    "text": "Hello, how do I connect my agent?",
    "html": "<p>Hello, how do I connect my agent?</p>",
    "attachments": []
  }
}
```

---

### `email.sent`

Triggered when an outbound email is accepted by the Wirebox edge engine for delivery.

```json
{
  "id": "evt_01J8ABC124",
  "event": "email.sent",
  "created_at": "2026-09-11T12:01:00Z",
  "data": {
    "message_id": "msg_01J8OUTBOUND789",
    "thread_id": "thrd_01J8GHI789",
    "agent_handle": "eva",
    "to": ["alex@example.com"],
    "subject": "Re: Need help with integration"
  }
}
```

---

### `email.delivered`

Triggered when the recipient's mail server confirms successful delivery.

```json
{
  "id": "evt_01J8ABC125",
  "event": "email.delivered",
  "created_at": "2026-09-11T12:02:15Z",
  "data": {
    "message_id": "msg_01J8OUTBOUND789",
    "thread_id": "thrd_01J8GHI789",
    "agent_handle": "eva",
    "recipient": "alex@example.com",
    "response": "250 2.0.0 OK: message queued 1048201"
  }
}
```

---

### `email.bounced`

Triggered when a remote mail server rejects an outbound email (e.g. mailbox not found, domain non-existent).

```json
{
  "id": "evt_01J8ABC126",
  "event": "email.bounced",
  "created_at": "2026-09-11T12:03:00Z",
  "data": {
    "message_id": "msg_01J8OUTBOUND789",
    "thread_id": "thrd_01J8GHI789",
    "agent_handle": "eva",
    "recipient": "invalid-address@example.com",
    "bounce_type": "permanent",
    "diagnostic_code": "550 5.1.1 User unknown"
  }
}
```

---

### `email.failed`

Triggered when an outbound email fails permanently after exhausting all retry attempts.

```json
{
  "id": "evt_01J8ABC135",
  "event": "email.failed",
  "created_at": "2026-09-11T12:05:00Z",
  "data": {
    "message_id": "msg_01J8OUTBOUND789",
    "thread_id": "thrd_01J8GHI789",
    "agent_handle": "eva",
    "error_code": "system_error",
    "error_message": "Outbound delivery permanently failed after retry limit."
  }
}
```

## SMS Events

### `sms.received`

Triggered immediately when an incoming SMS or MMS arrives on an agent's phone number.

```json
{
  "id": "evt_01J8ABC140",
  "event": "sms.received",
  "created_at": "2026-09-18T02:15:00Z",
  "data": {
    "message": {
      "id": "msg_01J8DEF111",
      "channel": "sms",
      "phone_number": "+14232190980",
      "agent_handle": "sale-mark",
      "direction": "inbound",
      "type": "sms",
      "from_number": "+15551234567",
      "to_numbers": ["+14232190980"],
      "text": "Your verification code is 482910",
      "media": null,
      "has_media": false,
      "segments": 1,
      "created_at": "2026-09-18T02:15:00Z"
    }
  }
}
```

---

### `sms.sent`

Triggered when an outbound SMS/MMS has been dispatched to the telephony carrier.

```json
{
  "id": "evt_01J8ABC141",
  "event": "sms.sent",
  "created_at": "2026-09-18T02:16:00Z",
  "data": {
    "message_id": "msg_01J8DEF222",
    "phone_number": "+14232190980",
    "to": "+15551234567",
    "sent_at": "2026-09-18T02:16:00Z"
  }
}
```

---

### `sms.delivered`

Triggered when the cellular carrier confirms delivery of the SMS to the recipient's handset.

```json
{
  "id": "evt_01J8ABC142",
  "event": "sms.delivered",
  "created_at": "2026-09-18T02:16:05Z",
  "data": {
    "message_id": "msg_01J8DEF222",
    "phone_number": "+14232190980",
    "recipient": "+15551234567",
    "delivered_at": "2026-09-18T02:16:05Z"
  }
}
```

---

### `sms.failed`

Triggered when SMS delivery fails permanently (e.g. carrier block, unreachable handset, or opt-out).

```json
{
  "id": "evt_01J8ABC143",
  "event": "sms.failed",
  "created_at": "2026-09-18T02:16:10Z",
  "data": {
    "message_id": "msg_01J8DEF222",
    "phone_number": "+14232190980",
    "recipient": "+15551234567",
    "error_code": "unreachable",
    "error_message": "Destination handset unreachable",
    "failed_at": "2026-09-18T02:16:10Z"
  }
}
```

## iMessage Events

### `imessage.connected`

Triggered when a human user connects to an agent identity via the router line (e.g. by texting `connect @agent` or scanning the QR code).

```json
{
  "id": "evt_01J8ABC131",
  "event": "imessage.connected",
  "created_at": "2026-09-17T10:28:00Z",
  "data": {
    "conversation_id": "conv_01J8ABC123XYZ",
    "agent_handle": "eva",
    "participant_id": "+15551234567",
    "connected_at": "2026-09-17T10:28:00Z"
  }
}
```

---

### `imessage.disconnected`

Triggered when an active iMessage conversation session is explicitly disconnected (via API or session release).

```json
{
  "id": "evt_01J8ABC132",
  "event": "imessage.disconnected",
  "created_at": "2026-09-17T11:00:00Z",
  "data": {
    "conversation_id": "conv_01J8ABC123XYZ",
    "agent_handle": "eva",
    "participant_id": "+15551234567",
    "disconnected_at": "2026-09-17T11:00:00Z"
  }
}
```

---

### `imessage.received`

Triggered when an incoming iMessage bubble arrives from a user directed to an agent identity.

```json
{
  "id": "evt_01J8ABC127",
  "event": "imessage.received",
  "created_at": "2026-09-17T10:30:00Z",
  "data": {
    "message_id": "imsg_01J8DEF456GHI",
    "conversation_id": "conv_01J8ABC123XYZ",
    "agent_handle": "eva",
    "sender": "+15551234567",
    "text": "Hello Eva, can you summarize my tasks today?",
    "media_url": null,
    "received_at": "2026-09-17T10:30:00Z"
  }
}
```

---

### `imessage.sent`

Triggered when an outbound iMessage has been successfully dispatched through the gateway.

```json
{
  "id": "evt_01J8ABC128",
  "event": "imessage.sent",
  "created_at": "2026-09-17T10:30:05Z",
  "data": {
    "message_id": "imsg_01J8DEF456GHJ",
    "conversation_id": "conv_01J8ABC123XYZ",
    "agent_handle": "eva",
    "recipient": "+15551234567",
    "text": "You have 3 tasks scheduled for today.",
    "media_url": null,
    "sent_at": "2026-09-17T10:30:05Z"
  }
}
```

---

### `imessage.delivered`

Triggered when Apple confirms the blue bubble has been delivered to the recipient's device.

```json
{
  "id": "evt_01J8ABC129",
  "event": "imessage.delivered",
  "created_at": "2026-09-17T10:30:08Z",
  "data": {
    "message_id": "imsg_01J8DEF456GHJ",
    "conversation_id": "conv_01J8ABC123XYZ",
    "agent_handle": "eva",
    "recipient": "+15551234567",
    "delivered_at": "2026-09-17T10:30:08Z"
  }
}
```

---

### `imessage.failed`

Triggered when an outbound iMessage delivery attempt fails (e.g. recipient phone number is not registered with Apple iMessage).

```json
{
  "id": "evt_01J8ABC130",
  "event": "imessage.failed",
  "created_at": "2026-09-17T10:30:10Z",
  "data": {
    "message_id": "imsg_01J8DEF456GHJ",
    "conversation_id": "conv_01J8ABC123XYZ",
    "agent_handle": "eva",
    "recipient": "+15551234567",
    "error_code": "not_registered",
    "error_message": "Recipient is not registered with Apple iMessage",
    "failed_at": "2026-09-17T10:30:10Z"
  }
}
```

## System Events

### `test.ping`

Diagnostic event sent when testing a webhook endpoint from the Console or API.

```json
{
  "id": "evt_01J8TEST999",
  "event": "test.ping",
  "created_at": "2026-09-11T12:00:00Z",
  "data": {
    "message": "This is a diagnostic ping event from Wirebox.",
    "webhook_id": "whk_01J8DEF456GHI789"
  }
}
```
