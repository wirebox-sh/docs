---
title: "Create Webhook"
api: "POST https://api.wirebox.sh/api/v1/webhooks"
description: "Register an HTTPS endpoint to receive real-time event notifications."
---

### Body Parameters

<ParamField body="url" type="string" required>
  Target HTTPS destination URL (e.g. `https://agent.example.com/api/webhooks`).
</ParamField>

<ParamField body="events" type="string[]" required>
  Array of event types to subscribe to (e.g. `["email.received", "email.sent", "sms.received"]`).
</ParamField>

<ParamField body="agent" type="string">
  Optional agent handle to scope events exclusively to this agent.
</ParamField>

<ParamField body="mailbox" type="string">
  Optional mailbox address to scope events to a single mailbox.
</ParamField>

<ParamField body="auth_token" type="string">
  Optional custom bearer token (min 8 chars). When set, Wirebox will send `Authorization: Bearer <auth_token>`.
</ParamField>

### Response

Returns the webhook endpoint with its one-time HMAC signing secret.

<RequestExample>
```bash cURL
curl -X POST https://api.wirebox.sh/api/v1/webhooks \
  -H "Authorization: Bearer $WIREBOX_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://agent.example.com/api/webhooks",
    "events": ["email.received", "email.sent", "sms.received"],
    "agent": "eva"
  }'
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    webhook = wirebox.webhooks.create(
        url="https://agent.example.com/api/webhooks",
        events=["email.received", "email.sent", "sms.received"],
        agent="eva"
    )
    print(f"Created webhook: {webhook.id}")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const webhook = await wirebox.webhooks.create({
  url: "https://agent.example.com/api/webhooks",
  events: ["email.received", "email.sent", "sms.received"],
  agent: "eva",
});
console.log(`Created webhook: ${webhook.id}`);
```

```bash CLI
wirebox webhook create \
  --url https://agent.example.com/api/webhooks \
  --events email.received,email.sent,sms.received \
  --agent eva
```
</RequestExample>
