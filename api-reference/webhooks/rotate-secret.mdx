---
title: "Rotate Webhook Secret"
api: "POST https://api.wirebox.sh/api/v1/webhooks/{id}/rotate-secret"
description: "Immediately invalidate the current HMAC secret and generate a replacement secret."
---

### Path Parameters

<ParamField path="id" type="string" required>
  The unique webhook ID.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.wirebox.sh/api/v1/webhooks/whk_01J8DEF456GHI789/rotate-secret \
  -H "Authorization: Bearer $WIREBOX_API_KEY"
```

```python Python
from wirebox import Wirebox

with Wirebox() as wirebox:
    res = wirebox.rotate_webhook_secret("whk_01J8DEF456GHI789")
    print("New Secret:", res["secret"])
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wirebox = new Wirebox();
const res = await wirebox.rotateWebhookSecret("whk_01J8DEF456GHI789");
console.log("New Secret:", res.secret);
```

```bash CLI
wirebox webhook rotate-secret whk_01J8DEF456GHI789
```
</RequestExample>
