title: "Webhooks"
description: "Real-time HTTP push notifications with Bearer Token and HMAC-SHA256 signature verification."
---

Webhooks deliver real-time HTTP POST notifications to your backend servers whenever events occur across your agent mailboxes. Instead of continuously polling for new messages, webhooks let your agents respond instantly to inbound emails and delivery status changes.

---

## Supported Event Types

| Event Type | Channel | Description |
| :--- | :--- | :--- |
| `message.received` | Mail | An inbound email was received, parsed, and stored in an agent inbox. |
| `message.sent` | Mail | An outbound email was accepted and dispatched to the recipient's mail exchange server. |
| `message.delivered` | Mail | The remote mail server confirmed successful delivery of the outbound email. |
| `message.bounced` | Mail | The remote mail server rejected the email (e.g. invalid recipient or mailbox full). |
| `message.failed` | Mail | Outbound delivery failed permanently after edge retries. |
| `test.ping` | System | Diagnostic ping fired from the Console or API to verify endpoint connectivity. |

---

## Managing Webhooks

You can configure, inspect, test, and manage webhook subscriptions programmatically via the Python SDK, TypeScript SDK, or the terminal CLI.

### Creating a Webhook

Register a new HTTPS endpoint to receive agent events. You can optionally restrict the webhook to a specific agent handle or configure a custom Bearer auth token:

<CodeGroup>
```python Python
from wirebox import Wirebox

with Wirebox() as wb:
    webhook = wb.create_webhook(
        url="https://agent.example.com/api/webhooks",
        events=["message.received", "message.delivered"],
        agent="eva",
        auth_token="optional_bearer_token"
    )
    print("Webhook ID:", webhook.id)
    print("Signing Secret:", webhook.secret)
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wb = new Wirebox();

const webhook = await wb.webhooks.create({
  url: "https://agent.example.com/api/webhooks",
  events: ["message.received", "message.delivered"],
  agent: "eva",
  auth_token: "optional_bearer_token",
});

console.log("Webhook ID:", webhook.id);
console.log("Signing Secret:", webhook.secret);
```

```bash CLI
wirebox webhook create \
  --url https://agent.example.com/api/webhooks \
  --events message.received,message.delivered \
  --agent eva \
  --auth-token optional_bearer_token
```
</CodeGroup>

### Listing Webhooks

Query all configured webhook subscriptions across your organization, or filter by agent handle:

<CodeGroup>
```python Python
from wirebox import Wirebox

with Wirebox() as wb:
    webhooks = wb.list_webhooks(agent="eva")
    for wh in webhooks:
        print(f"[{wh.status}] {wh.id}: {wh.url} ({wh.events})")
```

```ts TypeScript
import { Wirebox } from "@wirebox-sh/sdk";

const wb = new Wirebox();

const webhooks = await wb.webhooks.list({ agent: "eva" });
for (const wh of webhooks) {
  console.log(`[${wh.status}] ${wh.id}: ${wh.url} (${wh.events.join(", ")})`);
}
```

```bash CLI
# Formatted terminal table
wirebox webhook list --agent eva

# Raw JSON (ideal for subagent automation or jq)
wirebox webhook list --agent eva --json
```
</CodeGroup>

## Authentication & Verification

Wirebox provides two complementary layers of authentication to ensure incoming webhooks originate legitimately from Wirebox.

### 1. Custom Auth Token (Bearer Authentication)

The simplest method. When registering a webhook endpoint, supply an optional `auth_token`:

```http
Authorization: Bearer my-custom-secret-token
```

Your receiving server simply validates this header:

<CodeGroup>
```python Python (FastAPI)
from fastapi import FastAPI, Header, HTTPException

app = FastAPI()
EXPECTED_TOKEN = "Bearer my-custom-secret-token"

@app.post("/api/webhooks")
async def receive_webhook(authorization: str = Header(None)):
    if authorization != EXPECTED_TOKEN:
        raise HTTPException(status_code=401, detail="Unauthorized")
    return {"received": True}
```

```ts Node.js (Express)
if (req.headers["authorization"] !== `Bearer ${process.env.WEBHOOK_SECRET}`) {
  return res.status(401).send("Unauthorized");
}
```
</CodeGroup>

---

### 2. Zero-Trust HMAC-SHA256 Verification

For cryptographic tamper-proofing, every webhook endpoint is issued a signing secret (`whsec_...`). Wirebox signs the payload using HMAC-SHA256 and includes the signature in the header:

```http
X-Wirebox-Signature-256: t=1726051200,v1=9a8b7c6d5e4f3a2b1c0...
```

The string to sign is constructed as:
```text
string_to_sign = "t=" + timestamp + "." + raw_body
```

#### Official SDK Verification (Recommended)

Both the Python and TypeScript SDKs provide built-in, timing-safe verification:

<CodeGroup>
```python Python
from wirebox import verify_webhook

# In your FastAPI, Flask, or Django handler:
is_valid = verify_webhook(
    raw_body=raw_body_bytes,
    signature_header=request.headers.get("X-Wirebox-Signature-256"),
    secret="whsec_your_signing_secret",
    tolerance_seconds=300 # 5-minute replay attack window
)

if not is_valid:
    raise HTTPException(status_code=401, detail="Invalid signature")
```

```ts TypeScript
import { verifyWebhook } from "@wirebox-sh/sdk";

// In your Express, Next.js, or Hono handler:
const isValid = verifyWebhook(
  rawBody,
  req.headers["x-wirebox-signature-256"],
  "whsec_your_signing_secret",
  { toleranceSeconds: 300 }
);

if (!isValid) {
  res.status(401).send("Invalid signature");
}
```
</CodeGroup>

#### Manual HMAC Verification

If you are implementing verification manually without the SDK:

<CodeGroup>
```python Python
import hmac
import hashlib
import time

def verify_wirebox_signature(raw_body: bytes | str, signature_header: str, secret: str, tolerance: int = 300) -> bool:
    pairs = dict(item.strip().split("=", 1) for item in signature_header.split(",") if "=" in item)
    timestamp = pairs.get("t")
    v1_sig = pairs.get("v1")
    if not timestamp or not v1_sig:
        return False
    if abs(time.time() - int(timestamp)) > tolerance:
        return False
    body_str = raw_body.decode("utf-8") if isinstance(raw_body, bytes) else raw_body
    payload = f"t={timestamp}.{body_str}".encode("utf-8")
    expected = hmac.new(secret.encode("utf-8"), payload, hashlib.sha256).hexdigest()
    return hmac.compare_digest(v1_sig, expected)
```

```ts Node.js
import crypto from "node:crypto";

export function verifyWireboxWebhook(
  rawBody: string,
  signatureHeader: string,
  secret: string,
  toleranceSeconds = 300
): boolean {
  // 1. Parse header components
  const elements = signatureHeader.split(",");
  let timestamp: string | null = null;
  const signatures: string[] = [];

  for (const element of elements) {
    const [key, value] = element.trim().split("=");
    if (key === "t") timestamp = value;
    if (key === "v1") signatures.push(value);
  }

  if (!timestamp || signatures.length === 0) return false;

  // 2. Prevent replay attacks
  const currentTime = Math.floor(Date.now() / 1000);
  if (Math.abs(currentTime - parseInt(timestamp, 10)) > toleranceSeconds) {
    return false;
  }

  // 3. Compute expected signature
  const payloadToSign = `t=${timestamp}.${rawBody}`;
  const expectedSignature = crypto
    .createHmac("sha256", secret)
    .update(payloadToSign, "utf8")
    .digest("hex");

  // 4. Constant-time comparison
  for (const sig of signatures) {
    if (
      crypto.timingSafeEqual(
        Buffer.from(sig, "hex"),
        Buffer.from(expectedSignature, "hex")
      )
    ) {
      return true;
    }
  }

  return false;
}
```
</CodeGroup>

## Idempotency & Retries

* **Idempotency**: Every webhook payload contains a unique, stable `id`. If your server receives the same `id` more than once, safely acknowledge and discard the duplicate.
* **Automatic Retries**: If your server returns a non-2xx status code or does not respond within 10 seconds, Wirebox retries delivery with exponential backoff up to 5 times.
