Wirebox integrates with AI clients and agent harnesses through the [Wirebox MCP server](/mcp). Each integration connects a client to one agent identity — its mailbox and iMessage conversations — using a standard API key.

## Available integrations

| Integration | Surface | Transport |
| :--- | :--- | :--- |
| [Cursor](/integrations/cursor) | [Cursor](https://cursor.com) | Remote HTTP |
| [Claude Code](/integrations/claude-code) | [Claude Code](https://claude.com/claude-code) | Remote HTTP or stdio |
| [Claude Desktop](/integrations/claude-desktop) | [Claude Desktop](https://claude.ai/download) | stdio (`npx`) |

Any other MCP-compatible client can connect to the hosted endpoint directly — see [Connect](/mcp#connect) for the URL and authentication options.

## What an integration adds

Depending on the client, a Wirebox connection provides:

* read, search, send, reply to, and delete email from the agent's mailbox
* read and send iMessage conversations
* a `wirebox_whoami` check to confirm which identity the connection acts as

All actions follow the identity's mail rules and security policy, and the MCP server never acts on its own — inbound automation needs [webhooks](/capabilities/webhooks) and a runtime that invokes your model.
