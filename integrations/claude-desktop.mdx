title: "Claude Desktop"
description: "Run the Wirebox stdio bridge for Claude Desktop."
---

Claude Desktop connects to MCP servers over stdio, so it runs the published `@wirebox-sh/mcp` package locally. Some builds can also add remote servers from Settings → Connectors; if yours offers that, the [hosted endpoint](/mcp#hosted-endpoint) works there too. Otherwise use the configuration below.

## Connect

1. Create an API key in the [Console](https://wirebox.sh/console/keys).

2. Open your Claude Desktop configuration file:

   * **macOS** — `~/Library/Application Support/Claude/claude_desktop_config.json`
   * **Windows** — `%APPDATA%\Claude\claude_desktop_config.json`

3. Add the Wirebox server:

   ```json
   {
     "mcpServers": {
       "wirebox": {
         "command": "npx",
         "args": ["-y", "@wirebox-sh/mcp"],
         "env": {
           "WIREBOX_API_KEY": "wb_live_your_api_key_here",
           "WIREBOX_IDENTITY": "eva"
         }
       }
     }
   }
   ```

   `WIREBOX_IDENTITY` is optional; set it when the key can access more than one identity.

4. Quit Claude Desktop completely and reopen it. The configuration is only read at startup.

## Verify

Ask Claude to call `wirebox_whoami`. It returns the handle, mailbox address, and iMessage status of the identity the connection acts as. The Wirebox tools also appear in the tools menu of the composer.

## What Claude Desktop can do

* List, search, read, send, reply to, and delete email in the agent's mailbox
* List and read iMessage conversations, and send iMessages
* Check which identity the connection acts as

Sends follow the identity's [mail rules and policy](/api-reference/mail/rules), and the connection only acts when Claude calls a tool.

## Pin the identity

If the machine also hosts other Wirebox processes, or you want to be certain the model cannot switch identities, add these keys to the `env` object:

```json
"WIREBOX_IDENTITY": "eva",
"WIREBOX_IDENTITY_LOCKED": "1"
```

Locking pins every call to `WIREBOX_IDENTITY` and removes the `identity` argument from the tool schemas.

## Troubleshooting

| Symptom | Fix |
| :--- | :--- |
| No Wirebox tools in the composer | Validate the JSON, then fully restart Claude Desktop. |
| Tools return an authorization error | The key is invalid or revoked — create a new one and update `env`. |
| Tools act as an unexpected identity | Set `WIREBOX_IDENTITY`, or use an identity-scoped API key. |
| `npx` cannot be found | Install Node.js 18+ and make sure `npx` is on the PATH Claude Desktop sees. |

See [Wirebox MCP Server](/mcp) for the full tool catalog, environment variables, and identity locking.
