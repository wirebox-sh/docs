## Set up

<CodeGroup>
```bash npm (SDK)
npm install @wirebox/sdk
```

```bash CLI
npm install -g @wirebox/cli
```
</CodeGroup>

Requires Node.js ≥ 18 (TypeScript SDK and CLI).

---

## Authentication

You will need a Wirebox API key. Obtain one from the [Wirebox Console](https://wirebox.sh/console) or let your agent self-register via [Agent Self-Signup](/agent-signup).

#### Environment Variable

Export your API key in your terminal or `.env` file:

```bash
export WIREBOX_API_KEY="wb_live_your_secret_key_here"
```

#### CLI Resolution & Flags

The CLI automatically resolves your key from the `WIREBOX_API_KEY` environment variable. You can also pass it explicitly with `--api-key`.

| Flag | Description |
| :--- | :--- |
| `--api-key <key>` | Wirebox API key (or `WIREBOX_API_KEY` environment variable) |
| `--base-url <url>` | Override API base URL (defaults to `https://api.wirebox.sh`) |
| `--json` | Output as raw JSON instead of formatted tables (ideal for AI subagents and `jq`) |

## Quick start

<CodeGroup>
```ts TypeScript
import { Wirebox } from "@wirebox/sdk";

// 1. Initialize client (automatically reads process.env.WIREBOX_API_KEY)
const wb = new Wirebox();

// 2. Create an agent identity — provisions eva@wireboxmail.com instantly
const identity = await wb.identities.create({
  agent_handle: "eva",
  display_name: "Eva Support",
  description: "Autonomous customer triage and support agent",
});
console.log(`Mailbox ready: ${identity.mailbox_address}`);

// 3. Bind directly to the agent context
const eva = await wb.identify("eva");

// 4. Send an outbound email
const sent = await eva.sendEmail({
  to: "user@example.com",
  subject: "Welcome from Eva",
  text: "Hello! I am Eva, your AI assistant. My mailbox is fully configured.",
});
console.log(`Message sent: ${sent.id}`);

// 5. Read incoming inbox messages
const { messages } = await eva.listMessages({ limit: 10 });
for (const msg of messages) {
  console.log(`[${msg.id}] From: ${msg.from} | Subject: ${msg.subject}`);
}
```

```bash CLI
# 1. Create an agent identity — provisions eva@wireboxmail.com instantly
wirebox identity create eva \
  --display-name "Eva Support" \
  --description "Autonomous customer triage and support agent"

# 2. Send an outbound email
wirebox mail send eva \
  --to user@example.com \
  --subject "Welcome from Eva" \
  --body "Hello! I am Eva, your AI assistant. My mailbox is fully configured."

# 3. Read incoming inbox messages (formatted table)
wirebox mail list eva --limit 10

# 4. Read incoming messages as raw JSON (for subagents or jq piping)
wirebox mail list eva --limit 10 --json
```
</CodeGroup>

Every agent identity has a stable, production email address derived from its handle:

| Resource | Address | Description |
| :--- | :--- | :--- |
| **Mailbox** | `eva@wireboxmail.com` | Receives inbound messages from Gmail, Outlook, or corporate domains |
